# Atlas v2.1 Launch Plan

Single source of truth for the v2.1 App Store submission. Phase
36d (this commit) applied the rename + listing copy + screenshot
spec. Bundle identifier stays `com.peptidesai.app` so existing
TestFlight + production installs survive the rebrand.

---

## 1 — Brand

### App name (display)
```
Atlas
```

### Subtitle (30 chars)
```
Track what compounds
```

### Brand reasoning

Atlas evokes mythology + strength + comprehensiveness — "the one
who carries everything." Fits the v2.1 reality where peptide
protocols are one column in a wider system that also tracks
nutrition, labs, body trends, daily check-ins, and biometrics.
Reads premium next to Oura, Whoop, Levels, Hone. One word, five
letters, easy to type, easy to say, works in every locale.

### Voice & tone

- **Confident, not clinical** — "Built for the long run," not
  "Optimise your peptide compliance regimen"
- **Specific over generic** — numbers + stat names where possible
- **Plain English** — no jargon, no acronyms in marketing copy
- **Lifestyle, not medical** — describe outcomes ("how the week
  went"), never diagnoses ("treat", "cure", "prescribe")

## 4 — App privacy labels

App Store Connect's privacy questionnaire answers for v2.1:

### Data collected — linked to user
- **None.** No accounts (Sign in with Apple is optional, no
  email gating), no analytics SDKs, no third-party identifiers.

### Data collected — not linked to user
- **Health & Fitness**
  - *Purpose:* App functionality (Sunday AI weekly recap)
  - *Linked to user:* No
  - *Used for tracking:* No
  - *Data:* Anonymised weekly aggregates (compliance %, streak
    length, check-in averages, HRV deltas). No peptide names, no
    entry timestamps, no identifiers. Sent to our Vercel proxy +
    forwarded to Anthropic for summarisation. Cleared from the
    server after the response is returned.

### Data NOT collected
Contact Info, User Content, Identifiers, Browsing History,
Purchases, Search History, Location, Sensitive Info, Diagnostics,
Financial Info, Contacts, Other.

### Tracking
**No tracking.** No data shared with data brokers, no SDK
cross-app identifiers, no advertising IDs.

`Info.plist` already declares four locales: `en`, `es`,
`zh-Hans`, `ja`. v2.1 ships translations across the full set.

| Locale | Listing copy | In-app strings | Notes |
|---|---|---|---|

| zh-Hans | ✓ ship in v2.1 | ✓ ship in v2.1 | Significant peptide community |
| ja | ✓ ship in v2.1 | ✓ ship in v2.1 | Premium-pricing territory |

### Translation method
Professional pass for the App Store listing (Apple's translation
service or a contractor — ~$200–$400 total). In-app strings are
already authored via `String(localized:)` + the
`Localizable.xcstrings` catalog, so the translation slots into
the existing pipeline. PeptideX→Atlas rename has already been
applied across the catalog as part of Phase 36d.

### Deferred to v2.2
German, French, Portuguese, Korean — smaller peptide community,
not worth gating v2.1 on.

## 9 — What's deliberately unchanged

The following stay "PeptideX"-flavoured on purpose:
- Repository name (`Peptide-ai` on GitHub — separate decision)
- Bundle identifier (`com.peptidesai.app`)
- Custom URL scheme (`peptidex://`)
- Internal Swift type names (`PeptideApp`, `PeptideListView`,
  `PeptideDatabase`, etc. — never user-visible)
- Folder structure (`Peptide/`, `PeptideWidgets/`,
  `PeptideWatch/` — cosmetic only)
- `APP_STORE_METADATA.md`, `HANDOFF.md`, `ROADMAP.md`,
  `CLAUDE.md` — historical / pre-v2.1 docs kept as archive
- The asset catalog `AppIcon` name (unchanged; what the user
  sees on Home Screen is `CFBundleDisplayName`, not the asset
  catalog entry)
