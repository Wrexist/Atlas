# PeptideX v2.1 Launch Plan

Single source of truth for the v2.1 App Store submission — new app
name, listing copy, screenshot spec, privacy labels, translation
plan, pricing references. **Nothing in this document has been
applied to the codebase yet** (Info.plist, About section, asset
catalog still say "PeptideX"). The intent is one review pass for
all the high-consequence decisions, then a single follow-up phase
that executes the renames + captures the screenshots.

---

## 1 — New app name

The app's centre of gravity has shifted from "peptide tracker" to
"performance optimisation platform" — peptides are still the
anchor, but doses share equal billing with nutrition, daily
check-ins, labs, body trends, and the new AI weekly recap. The
name should match.

### Recommendation: **Compound**

Tagline candidates:
- *Track what compounds.*  ← leading recommendation
- *Stack, log, optimise.*
- *The optimisation OS.*

Why Compound works:

| Dimension | Verdict |
|---|---|
| **Peptide adjacency** | Peptides *are* compounds. The chemistry overlap reads "for serious users" without being clinical |
| **Lifestyle reach** | "Compounding gains" / "compound interest" — biohacker / longevity audience already uses the word |
| **Brand strength** | One word, eight letters, hard consonants. Memorable, easy to type, easy to say |
| **App Store posture** | Premium feel — no jargon, no "X", no "Pro". Stands on its own next to Whoop, Oura, Strava |
| **ASO** | Generic enough that the App Store description, not the title, carries the keyword work |
| **Risk** | Slight chemistry overtone. Mitigated by lifestyle-flavoured subtitle + screenshots |

Bundle identifier stays `com.peptidesai.app` (changing it loses
all existing TestFlight + production installs). Display name +
marketing become "Compound".

### Runner-up: **Stack**

Stronger biohacker coding ("BPC stack", "morning stack"), shorter
(5 chars), but slightly narrower-feeling. If you'd rather stay
deeper inside the peptide community for v2.1 and broaden later,
Stack is the right pick. Subtitle: *Built for stacking.*

### Other options considered + rejected

- **Tempo** — too soft, loses the peptide cohort
- **Cadence** — clinical, generic
- **Loop** — saturated category (Loop the diabetes tool, Loop the band tool)
- **Form** — too generic
- **Vital** — Vital is the biggest current Apple Health–adjacent
  competitor's name; can't take it
- **Cycle** — owned by menstrual trackers
- **Phase** — chemistry overtone is too strong; reads "phase
  changes / lab" not "lifestyle"

### Capture mechanics

**iOS:** capture in iPhone 16 Pro Max simulator (6.9" — Apple's
required size). Also re-export at 6.7" + iPad Pro 13" for full
device coverage.

**Seed data:** new launch flag `-screenshotMode YES` injects a
believable profile — 4 active protocols, 21 logged meals across
the week, 14 outcome check-ins (gradual upward trend),
representative labs, HRV uptrend. Status-bar override via
`xcrun simctl status_bar` to 9:41, full battery, full signal.

**Composite:** Figma master template — single source for the
tinted gradient backdrop, headline typography, padding. Each
screenshot is a smart-object swap on the master. ~30 minutes per
screenshot once the template exists; ~4 hours total for 8
screenshots across 3 device sizes.

  only for the first submission, localised composites in a
  follow-up. App Store accepts per-locale screenshot sets.
- **Demo data persona name** — recommend "Alex" (gender-neutral,
  short, recognisable). Avatar: default placeholder.

## 4 — App privacy labels

App Store Connect's privacy questionnaire. Answers for v2.1:

### Data collected — linked to user
- **None.** No accounts (auth is Sign in with Apple, optional),
  no analytics SDKs, no third-party identifiers.

### Data collected — not linked to user
- **Health & Fitness**
  - *Purpose:* App functionality (Sunday AI weekly recap)
  - *Linked to user:* No
  - *Used for tracking:* No
  - *Data:* Aggregated weekly stats (compliance %, streak length,
    check-in averages, HRV deltas). Sent to our server proxy +
    forwarded to Anthropic for AI summarisation. No peptide
    names, no entry timestamps, no identifiers. Cleared from the
    server after the response is returned.

### Data NOT collected
- Contact Info, User Content, Identifiers, Browsing History,
  Purchases, Search History, Location, Sensitive Info,
  Diagnostics, Financial Info, Contacts, Other.

### Tracking
- **No tracking.** No data shared with data brokers, no SDK
  cross-app identifiers, no advertising IDs.

## 5 — Translation plan

`Info.plist` already declares four locales: `en`, `es`, `zh-Hans`,
`ja`. v2.1 priorities:

1. **English (primary)** — all listing copy ships with v2.1
2. **Spanish (es)** — high-leverage second locale for the
   Americas. Ship listing copy + in-app strings in v2.1
3. **Chinese Simplified (zh-Hans)** — significant peptide
   community in greater China. Ship listing copy + in-app strings
4. **Japanese (ja)** — smaller install base but premium-pricing
   territory. Ship listing copy + in-app strings

**Translation method:** professional pass for App Store listing
(via Apple's translation service or a contractor — ~$200-$400 for
the four assets in three locales). In-app strings already use
`String(localized:)` + the `.xcstrings` catalog, so the
translation pass slots into the existing pipeline.

**Defer to v2.2:** German, French, Portuguese. The peptide
community in those locales is smaller; not worth gating v2.1 on
those translations.
