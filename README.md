# PeptideX

AI-powered peptide research and discovery iOS app.

## Project Structure

```
Peptide/          iOS app (SwiftUI)
scripts/          Tooling and data pipelines
  peptide-dataset/  Dataset builder for peptide data (see its README)
```

## Getting Started

Open the Xcode project and build for iOS simulator or device.

## Dataset Builder

See [scripts/peptide-dataset/README.md](scripts/peptide-dataset/README.md) for the Python pipeline that generates the peptide dataset.
