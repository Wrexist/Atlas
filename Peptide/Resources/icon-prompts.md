## Usage Tips

- **Midjourney:** Append `--ar 1:1 --s 750 --q 2` for best results. Use `--no gradient, text, watermark, badge` as negative.
- **DALL-E 3:** These prompts work as-is. Request "square" aspect ratio in the interface.
- **Ideogram:** Select "3D Render" style. Set aspect ratio to 1:1.
- **Post-processing:** After generation, apply the iOS icon mask (superellipse / squircle) and verify the icon reads clearly at 60x60, 120x120, and 180x180 px.
- **Color check:** Ensure the green accents land close to `#4A7C59` (dark) or `#6BAF7E` (light) — adjust saturation in post if the AI drifts toward teal or lime.
